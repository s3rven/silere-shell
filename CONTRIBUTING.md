# Contributing

Just open a PR — bug fix, typo, a whole new widget, or a half-finished idea to talk about. Anything's fair game and I'll review it myself.

AI-assisted PRs are welcome, and so is hand-written code. Neither is better here — just run what you send and make sure it works. Silere itself is built the same way; see [On AI assistance](README.md#on-ai-assistance).

Optional: `bash scripts/check.sh` runs the same checks CI does, if you'd rather not wait on a CI round-trip. Questions and loose ideas are fine in [Discussions](https://github.com/s3rven/silere-shell/discussions).
