# Silere Shell 0.5.0

Released 2026-08-13.

**Upgrading:** re-run the installer. Matugen now writes
`$XDG_CONFIG_HOME/matugen/silere-shell.json` instead of a file inside the checkout,
and until your `config.toml` points there, wallpaper colours stop changing and the
shell falls back to its bundled palette. If that file has an unpaired
`# silere-shell` marker the installer declines to touch it and says so; repair the
pair, then re-run.

## Added

- **Include AUR packages** toggle under Settings › System › Updates, counting
  updates through paru or yay when one is installed. On by default. Checks stay
  read-only and never install anything.
- Settings › Theme and Settings › System › Maintenance name whether Matugen is
  missing or has simply not written a palette yet.

## Changed

- Matugen palettes live-reload from a user-writable JSON file, which also makes
  read-only packaged installs work.
- Text no longer scales on hover or press. Surfaces still react; the text on them
  stays put.
- Text renders with distance fields rather than snapping to a device pixel grid.
- Buttons, pills, chips, toggles, media controls and slider handles share one hover
  and press response, quicker in than out.
- The bundled fallback accent is Silere's own default accent rather than white.
- Renamed the theme Source option from Neutral to Custom, and the accent picker's
  custom swatch to Mix, so the two no longer share a name.

## Removed

- Keyboard navigation and its accessibility metadata. Tab order, arrow-key
  stepping, focus rings, the settings sidebar's keyboard cursor and every
  `Accessible` role, name and description are gone; the shell is pointer-driven.
  Escape still steps back and closes, scrolling works everywhere it did, and the
  Wi-Fi password field still takes typed input. **Screen readers can no longer
  describe the shell.**

## Fixed

- A saved Wi-Fi network whose password had changed can be reconnected. A refused
  key offers a retype, and a wrong key reads as **Wrong password** rather than
  **Failed**.
- The installer names the compositor it found on an unsupported session and asks
  before writing. A Hyprland or niri config on disk still counts, so installing
  before the compositor is up keeps working.
- `scripts/install.sh --help` prints usage, and an unknown option exits 2 without
  writing anything.
- The media visualizer and track marquee no longer freeze on the only visible bar
  when focus moves to a monitor with the bar disabled.
- The screenshot watcher gives up when no screenshot directory exists instead of
  respawning every 60 seconds.
- Notification history labels days correctly across a daylight-saving change.
- A hung update check, package check or VPN lookup recovers through one shared
  bounded-process timeout.
- Optional-tool and font detection refresh cleanly at runtime.
- The workspace and window models no longer rebuild for a compositor event carrying
  nothing they read.
- Changing the clock's date style, or middle-clicking the clock, writes the settings
  file once.
- The first settings section opened in a session no longer stutters.
- Settings row names keep a readable floor when space runs short; the value shortens
  first.
- Dropdown options and the Wi-Fi and Bluetooth list placeholders keep the shared row
  height above 100% interface scale, so dividers stay on the same rhythm.
- The Wi-Fi password field is marked sensitive to input methods, so an IME or
  on-screen keyboard no longer capitalises a case-sensitive key or keeps it in
  predictive-text history.
- The settings panel eases to its new height when a category collapses.
- The palette card no longer bulges while switching theme Source between Custom and
  Wallpaper.
- Corrected the generated Cava profile's smoothing range.
