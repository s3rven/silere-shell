# Silere Shell 1.1.1

Released 2026-09-17.

**Upgrading:** dynamic workspaces are gone. If you had them on, the strip returns to the
fixed number of slots set under Settings › Workspaces › Slots shown.

## Removed

- Dynamic workspaces, and the new-workspace slot that came with them. The strip shows
  the number of slots set under Workspaces › Slots shown.
